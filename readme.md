# Custom scripts and files for de Jong et al. (2025)  

This repository contains custom code and data used to model local and global respiratory virus genomic surveillance infrastructure.

> Simon P.J. de Jong, Brooke E. Nichols, Anniek de Ruijter, Edyth Parker, Vera Mitesser, Christian Happi, Menno D. de Jong, Alvin X. Han, Colin A. Russell. (2025). Global solidarity in genomic surveillance improves early detection of acute respiratory virus threats.

 Scripts underlying the results are available with instructions in the ```scripts``` folder. Code used to generate the figures with instructions is available in the ```figures``` folder. Simulation output is available in the ```output``` folder.
