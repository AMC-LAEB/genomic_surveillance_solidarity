This folder contains R scripts to generate figures. Running the scripts requires the ```ggplot2```, ```patchwork```, ```ggsci```, ```scales```, ```ggridges```, ```dplyr```, ```tidyr```, ```ggpubr```, ```RColorBrewer```, ```latex2exp```, ```lemon```, ```ggbeeswarm```, ```ggnewscale```, and ```viridis``` R packages.
